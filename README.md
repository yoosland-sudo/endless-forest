# 끝없는 숲 수호대

귀여운 다람쥐가 천년 도토리 나무를 지키는 1분짜리 웹 게임입니다. 폰 브라우저에서 주소만 열면 바로 할 수 있습니다.

## 지금 들어 있는 것 (1단계 · 손맛 확인)

- 일반 판 30~60초: 관문 바로 다음 웨이브에서 시작, 5초마다 웨이브, 9웨이브를 버티면 관문 도착
- 판마다 카드 3번 (시작 1장 + 4·7번째 웨이브), 같은 갈래 3장이면 세트 효과
- 10웨이브마다 보스 관문 '가시 대장' (최대 2분)
- 도토리로 영구 강화 3종 (도토리 힘 · 던지기 속도 · 나무 체력)
- 최고 기록, 칭호, 결과 화면의 '다음 목표', 효과음, 기록은 폰에 자동 저장

## 폴더

- `game/` — 실제 게임 (이 폴더만 인터넷에 올라감)
- `tools/prepare_assets.py` — 지난 프로젝트의 그림을 웹용으로 줄이고 폰트를 필요한 글자만 남김
- `tests/balance.js` — 판을 수백 번 자동으로 돌려 난이도 확인 (`node tests/balance.js`)
- `tests/snap.sh` — Edge로 폰 크기 화면을 찍어 확인
- `docs/` — 기획안 PDF (인터넷에 올리지 않음)

## 테스트용 주소 옵션

`?test&autoplay=normal&ff=20` 처럼 붙이면 자동으로 판을 진행합니다. `autoplay=boss`, `gate=10`, `lv=5`, `acorns=500`, `sheet`를 함께 쓸 수 있습니다. 일반 주소에서는 아무 영향이 없습니다.
